# ☕ Mochi Cafe Sales Analysis (Jan - Dec 2023)

A comprehensive data analytics project utilizing a dynamic dashboard to track, model, and evaluate the 2023 sales performance of a cafe business. This project bridges operational tracking with data-driven business intelligence to optimize revenue streams, uncover seasonal trends, and analyze customer behaviors.

## 📊 Business Performance Metrics
* **Total Revenue:** ₹82,304.50
* **Total Profit:** ₹32,921.80
* **Total Orders:** 9,741 
* **Quantity Sold:** 29,002 items
* **Customer Satisfaction:** Balanced 4.00/5.00 average rating

## 📈 Key Analytical Insights
* **Revenue Operations:** Identified a major seasonal performance peak in **February (10,180 units)**, followed by highly stabilized operational baselines averaging between ₹6,200 and ₹6,800 monthly.
* **Product Mix Analysis:** Evaluated volume performance across categories, identifying **Juice (4,505 units)**, **Coffee (3,531 units)**, and **Cake (3,467 units)** as the core top-line revenue drivers.
* **Predictive Pipeline Variables:** Mapped consumer behavior metrics revealing a completely uniform **25% distribution** across all four daily time slots (Morning, Afternoon, Evening, Night), alongside higher transactional frequencies on Mondays.

## 🛠️ Data Infrastructure & Features
* **Interactive Slicers:** Enabled dynamic cross-filtering by Day of the Week, Month, Category, Order Time, Customer Type, and Payment Mode.
* **Pipeline Monitoring:** Created automated visual reporting modules tracking sales by day, category breakdown, and item performance rankings.
